# Project Instructions

- Follow the Alibaba Java development conventions for generated code.
- Use English names for every newly created directory, source file, build artifact and backup file. Do not create Chinese file or directory names.
- The app display name is `Ellery Ledger`. User-facing UI text may be Chinese.
- The project root is `Ellery Ledger`. Keep newly created project paths and file names in English.
- Keep OCR local. Never upload screenshots or transaction text unless the user explicitly authorizes adding cloud recognition.
- OCR must create drafts. Only explicit user confirmation may turn a draft into a confirmed ledger entry.
- Do not generate review notes automatically. The note field is the user's own evaluation.

- Do not proactively package or install APKs. The user builds in Android Studio; use source compilation, lint and targeted tests unless they explicitly request an APK.
